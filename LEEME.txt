NOTES — GitHub Pages PWA

USE
- Open the secret Settings only by holding the footer for 3 seconds (except the acronym button). The palette is decorative. Holds suppress selection and the touch callout; note editing still supports text selection.
- Enter a 3-letter Hacked user code. Changes save automatically on this device; Done only closes Settings.
- Tap the title or body to edit. Both scroll in the central area, clipped behind the fixed header and footer.
- Position and font size remain independently adjustable. The body moves down if a long title would overlap it.
- Tap the bottom-right dots to arm acronym mode. Blue means armed. After the next different response produces an acronym, the button switches off automatically. Repeated responses preserve the armed state and the edited note.
- Only a DIFFERENT API response replaces the body. Repeated responses preserve edits, even after reloading.
- Clearing/changing the user code disconnects the previous source and clears its body and comparison baseline.
- Reset all clears the note and settings after confirmation.

APPEARANCE
- Android Light is the available preset. The fixed artwork is recreated with SVG/CSS from the supplied reference.
- Custom screenshot uploads and arbitrary font choices have been removed.
- iPhone variants and Android Dark await their reference images and are unavailable for now.
- Light mode is explicit and independent of the device's dark-mode setting. The native status bar is controlled by browser/PWA support; the app does not fabricate time or battery values.
- Font uses Roboto with Noto Sans/Arial fallbacks. Header/footer spacing and gestures are shared across future appearances.
- When the software keyboard opens, the footer is hidden instead of floating above it. The editor remains scrollable in the visible area; the footer returns after the keyboard closes.

ACRONYMS
- Lists are in characters.mjs, exactly in the supplied order.
- One character name per line. Spaces, digits and punctuation produce no blank lines.
- Repeated letters use successive entries, wrapping only after that letter's list is exhausted.
- If the complete API text names a listed person, that person is excluded from every line of the acronym. Matching ignores case, accents, spaces and punctuation; remaining candidates keep their order and rotation.
- Counters reset for each new API text. Accents fall back to the base letter, except explicitly supplied special-letter lists, such as Ñ, Ç and Å, which take precedence.
- Unsupported letters without a matching list are skipped.

FILES
- index.html / styles.css: English UI, fixed artwork and scrollable editable note.
- app.mjs: auto-save, editor, controls and layout.
- note-core.mjs / characters.mjs: state, response comparison and acronym conversion.
- note-poller.mjs: API polling with cancellation and stale-response protection.
- manifest.webmanifest / sw.js / icons/: installable offline app shell.

CHECKS
Run npm test with Node.js 20 or later. No dependency installation or build is required.
Tests use mocked API responses, never real user codes.
Browser visual checks on iPhone/Safari and Android remain necessary for mobile keyboard and native status-bar behavior.

DEPLOY
Publish the repository root to GitHub Pages using main / (root).
Keep all asset paths relative so the app works at /NOTAS/.
The API is polled every 2 seconds while the page is running; a slow request finishes or times out before another request for that source starts.
The API is never cached. Offline mode preserves the saved draft and settings, but receiving new information requires a connection.
